Correlating Resonance: see the frames in your coded corpus

You have coded a set of documents against a list of concepts. Correlating Resonance shows you which concepts tend to appear together, how firmly they hold together when the corpus is split in half, which concepts mark each group out, and who voices each group. It tells you what each result has earned the right to be called. It certifies nothing.

or try it on an example corpus
Trial setting: where the app pauses for you

In the trial you can choose how far the app runs before it pauses. Later settings run the earlier checklist items in order, without pausing between them.

Bring your matrix

A table with one row per document and one column per concept, saved as a CSV file. Columns that describe each document (who wrote it, when, what kind of document it is) can sit in the same file. Your file stays on this computer.
