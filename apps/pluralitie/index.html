Name the frames

Bring a finished corres analysis. This page proposes a working name and a description for each group of concepts, and shows you the documents that sit most squarely inside it. What it proposes is a starting point for your reading, not a finding.

Run an analysis in corres first ↗

What you need — the analysis file from corres
At the end of a corres run, use Download analysis for frame naming. That file carries the groups, the role and stability of every concept, and your own concept names. Nothing else is needed, and the original documents are not uploaded here.

Drop the corres analysis file here or click to browse a .json file written by corres
2Propose names

Each group is sent to a language model with its concepts, ranked by how often they appear across the corpus, and the model is asked for a short name and a description. The documents shown beside each frame are chosen by the server from your own matrix — the ones carrying the most of that group's concepts.
