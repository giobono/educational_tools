CorRes shows the frames in your coded corpus, and tells you plainly how far they've been tested.

CorRes shows the frames in a coded corpus. It finds which of your concepts appear together more often than their frequencies predict, tests whether those groupings hold up when your documents are split in half, and shows who voices each one. It doesn't code text: it works on a file you've already coded, with one row per document and one column per concept.

Start with your own coded file, or try one of our sample data sets to see how it works.

Open CorRes→

What it does

  • It removes frequency before it looks for structure. Common concepts appear with everything, so the method never uses raw co-occurrence. It measures how far each pair departs from what their frequencies alone would produce.
  • It tests whether a grouping is real. It splits the corpus into random halves, many times, and asks whether the grouping reappears.
  • It shows the chance line beside every key result: on the sample data now, and on your own file when we run the checks for you. That is what a corpus with the same concept frequencies and no real pattern produces, computed from the data itself.
  • When a result falls short of its chance line, it says so, and carries on.
  • It keeps the record. A decision log, a run history and a parameter record travel with the research, so a reviewer can see every judgement, every run and every setting.
  • The tool computes; you interpret. What a frame means is the researcher's reading, recorded as such.

What you need

  • One file: a row per document and a column per concept.
  • An email address, to sign in. There is no charge.

The sample data sets

  • Shown for research, behind sign-in. They can't be downloaded. Each shows its source and how to cite it.
  • Stored results are labelled as stored, with the date they were computed.
